# 20 тестів автомата `async`/`await` проти C#

Однакові сценарії. Pascal — `{$ASYNCMODE STATEMACHINE}`, C# — `async`/`await`.
Кожен рядок: номер, назва, мілісекунди виміряного інтервалу, `PASS` або `FAIL`.
Інтервал — або затримка виклику до першого `await`, або повний час до результату;
назва тесту каже, що саме міряється. Порівнювати варто рядки з тим самим номером.

```sh
tests/concurrency/sm-compare/run.sh
```

У таймований набір `tests/concurrency/comparison` ці тести не входять.

Стрес `await` (15 сценаріїв, ті самі об’єми в Pascal і C#):

```sh
tests/concurrency/sm-compare/run-stress.sh
```

Звіт останнього прогону — `stress-report.md`. Рядок стресу: номер, назва,
скільки `await` виконано, мілісекунди, контрольна сума, очікувана сума, `PASS`.
